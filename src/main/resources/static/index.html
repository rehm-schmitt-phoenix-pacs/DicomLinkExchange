DICOM Link Exchange (DLX) – Demo Server

Dies ist ein Demo-Server für die DLX-Spezifikation. Die API ermöglicht den sicheren Austausch von DICOM-Daten mittels Token-basierter Authentifizierung.

API-Endpunkte

MethodePfadBeschreibung
GET/dlx/v1/api_infoAPI-Informationen
GET/dlx/v1/token/{value}Token einlösen, erhält TFA-Fragen
POST/dlx/v1/tokentfa/{value}TFA-Antworten senden, erhält JWT
GET/dlx/v1/listVerfügbare Studien auflisten
GET/dlx/v1/download/{id}Datei herunterladen (z.B. Studie, Befund als PDF)
